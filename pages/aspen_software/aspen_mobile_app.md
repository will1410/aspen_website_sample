## Aspen Mobile

Aspen Mobile was built to be a browser-installed mobile web app. Users can save the progressive web app right from their phone's browser for easy access which includes all features available in Aspen Discovery. Alternatively, libraries can put Aspen Mobile in the Apple iOS and Google Play stores for download with the library's specific name and branding.
